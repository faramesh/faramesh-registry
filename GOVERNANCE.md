# Registry Governance

The Faramesh registry is governed as part of the Faramesh open source project.
Project-wide governance is maintained in:

https://github.com/faramesh/faramesh-core/blob/main/GOVERNANCE.md

Registry-specific expectations:

- catalog artifacts must be neutral and community-appropriate;
- new providers, policy packs, and framework profiles require maintainer review;
- maintainers may reject artifacts that are proprietary-only, unsafe by default,
  misleading, or not reproducible enough for users to inspect;
- signed artifacts must include accurate hashes and version metadata;
- security-sensitive provider changes require extra review.
